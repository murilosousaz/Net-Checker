# Net Checker 🌐

> ⚠️ **Atenção:** O código-fonte atualizado e o desenvolvimento ativo deste projeto encontram-se na branch **`develop`**.

---

## 📌 Como acessar o código do projeto

Para visualizar o código-fonte, testar e contribuir com as últimas alterações, altere para a branch `develop`:

### Via Terminal / Git CLI
```bash
# Clone o repositório (caso ainda não tenha clonado)
git clone https://github.com/murilosousaz/Net-Checker.git
cd net_checker

# Troque para a branch develop
git checkout develop
```

### Via GitHub / GitLab / Bitbucket
Utilize o menu suspenso de seleção de branches (seletor no canto superior esquerdo da lista de arquivos) e selecione **`develop`**.

---

## 📄 Estrutura das Branches

- **`main`**: Reservada para versões estáveis e publicadas.
- **`develop`**: Branch principal de trabalho onde estão mantidos os scripts em Python e documentações ativas.
